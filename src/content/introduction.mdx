Mastra is a TypeScript framework for building AI agents and AI-powered applications. It gives you the components to create, run, test, and operate agents in production.

You can build with the Mastra development kit or use the [Studio](https://mastra.ai/docs/studio/overview) - an interactive ui for your Mastra projects.

Mastra also offers tools for agent evaluation, observability, and deployment.

## Who Mastra is for?

Mastra is for developers and product teams who want to add reliable AI capabilities to an application or build an AI-native product.
It is particularly useful for:

- **TypeScript and JavaScript developers** who want a code-first agent framework.
- **Backend engineers** who need agents to use APIs, databases, files, or internal tools.
- **Product teams** building AI assistants into customer-facing products.

## Use Cases

Mastra can be used for AI applications across different domain:

**Customer support:** Build agents that answer product questions, find account information, draft replies, and route complex cases to a human.

**Internal copilots: Help employees work faster with AI that understands your domain, such as HR queries, clinical documentation, sales prep, or document generation.**

**Developer and DevOps automation:** Automate deployments, debug production issues, manage infrastructure, and handle on-call workflows.

**Data analysis agents:** Let users query databases and dashboards in natural language. Connect to your data sources and return answers, charts, or reports.
