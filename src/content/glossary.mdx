---
title: Glossary
description: Understand how terms are used across Mastra products
---

| Concept       | What it means                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------- |
| Agent         | Uses an LLM, instructions, and tools to solve an open-ended task.                                 |
| Tool          | Performs a defined action, such as calling an API, querying a database, or retrieving a document. |
| Workflow      | Runs a known sequence of typed steps with explicit control flow.                                  |
| Memory        | Preserves useful context across conversations or tasks.                                           |
| Studio        | Lets you test agents and workflows locally and inspect their behavior.                            |
| Observability | Records traces, metrics, tool calls, and evaluations so you can improve reliability.              |
