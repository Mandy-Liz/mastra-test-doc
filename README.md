## To edit locally, please follow the steps below:
- Fork this repository
- Run `git clone https://github.com/Dev-Liz/mastra-test-doc.git`
- Open folder in your favourite IDE
- Ensure you're in the docs folder, then run `npm install` to install all dependencies
- Run `npm run dev` to launch preview
- Edit and preview files as wanted
